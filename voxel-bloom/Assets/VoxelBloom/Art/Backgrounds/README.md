# Backgrounds

Drop a full-resolution **portrait** Home background (1080×1920 or larger, no UI on it) here:

    Assets/VoxelBloom/Art/Backgrounds/Resources/VBUI/Backgrounds/home_background.png

Home uses it automatically, full-screen (envelope). It then skips the 3D voxel scenery and keeps only the 3D pedestal and model.
The asset sheet holds only a 578×325 landscape card (`Docs/reference/extracted/Backgrounds/landscape.png`), which is too small
for a full-screen background.
