3. 3D ANIMAL ART DIRECTION
Create ORIGINAL, recognizable, high-quality voxel characters: fox, panda, yellow chick, white rabbit, lion, gray cat, brown bear, dog, penguin and elephant. Start by perfecting the first six visible in the mockup; build the others to the same standard.
Each character must have:
- Strong recognizable silhouette from front and three-quarter views.
- Anatomically suggestive but cute proportions, big expressive eyes, distinctive ears/beak/muzzle/tail/mane/trunk as applicable.
- Clean voxel grid construction, no random floating cubes, consistent cube size and material language.
- Thoughtful color blocking, polished nonmetallic materials, subtle specular highlights, ambient shading, soft contact shadows.
- Stable pivot, sensible bounds, correct scale and camera framing.
- A model data asset usable in Home preview AND as a destructible voxel model in Gameplay (or a documented conversion pipeline if separate optimized meshes are needed).

- Unique idle animation: gentle breathing, blink, head tilt, ear twitch or tail wag as appropriate. Touch reaction; smooth 360-degree preview rotation with drag.
- Respect mobile performance: mesh batching/instancing, limited animated objects, avoid Rigidbody on each idle voxel.

5. GAMEPLAY CONSISTENCY

- Character models selected for preview must not silently override the actual level's model; use level-defined models and an explicit preview-selection rule.
- The same recognizable animal design language must appear in gameplay models.
- No model parts remain suspended unintentionally after destruction. Separate logical voxels from pooled physical fragments.
- Progress must equal destroyed target voxels / initial target voxels; freshly started level 1 starts at 0%, resumed levels restore actual progress.
- Block values represent exact maximum target-voxel destruction; target eligibility and queue behavior remain deterministic.
- Use a hybrid destruction system: optimized intact geometry, pooled Rigidbody fragments with gravity, collisions and controlled lifetime; no thousands of active physics bodies.
