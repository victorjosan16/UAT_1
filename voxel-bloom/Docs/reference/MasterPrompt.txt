4. LEVEL SELECT
Five chapters, each with 20 levels:
1 Happy Animals (1-20); 2 Sweet World (21-40); 3 City Blocks (41-60); 4 Ocean Wonders (61-80); 5 Dream Collection (81-100).
Each chapter card shows thumbnail, progress, stars, lock state and play action. Unlocked chapters open level grid; locked chapters show unlock requirements. Level cards show number, stars, completion/current/locked state.

5. CORE GAMEPLAY
Top: pause, level number, three-star indicator, coins.
Upper area: rotating real 3D voxel model, blue background, left/right rotation buttons, pedestal, progress bar.
Middle: five attack queue slots and remaining destruction indicator.
Bottom: five-column by four-row numbered block board, Hammer, Shuffle and Color Bomb boosters.

Each voxel has unique ID, integer grid coordinate, color ID, active/destroyed state and surface accessibility state.
Each board block has a color and attack power from 2, 4, 8, 16, 32, 64.
On tapping a valid block: validate move; reserve block; animate into queue; identify accessible voxels of matching color; remove up to attack power voxels; animate destruction; update progress and board; check win/lose; save progress.
If fewer eligible voxels exist, remove only those and consume attack. Normal attacks never destroy other colors.
A voxel is exposed if one of six orthogonal neighbors is empty or outside the model. Recompute exposure after destruction.
Board generation uses level data and deterministic seed, with solvability validation. Avoid dead-end random boards.
Five slots form a visible FIFO attack queue. Use a controlled state machine and prevent conflicting input.
Allow horizontal drag and left/right buttons to rotate model smoothly without accidentally selecting board tiles.

6. VOXEL MODEL SYSTEM
Implement actual 3D voxel geometry, model data, colors, optimized mesh generation/instancing, exposed-face detection, destruction, pooled falling fragments, rotation and completion progress.
Avoid thousands of separate Update-driven GameObjects.
Create original recognizable voxel models: chicken, fox, cat, bear, bunny, panda, penguin, sheep, wolf, deer, lion, cake, ice cream, candy, car, bus, house, fish, crab, castle, robot and dragon.
Shapes must be recognizable by silhouette, not merely color. Store reusable voxel data assets.

7. COMBO
Implement consecutive efficient attacks triggering x2, x3, x4 and x5 combos. Show animated COMBO text, controlled particles, fragments, score, subtle screen shake and optional haptics. Pool effects and support reduced-effects setting.

8. PAUSE
Semi-transparent dark overlay and white rounded dialog with purple Pause ribbon. Buttons: green Resume, blue Restart, purple Settings and Close. Resume retains state; Restart restores level start; Settings opens audio/vibration/quality. Freeze timers and gameplay input while paused.

9. LEVEL COMPLETE

Double Reward uses verified rewarded-ad completion callback only; show unavailable state if no provider. Prevent duplicate claims; persist immediately.

10. BOOSTERS
Hammer: destroy configurable selected voxels regardless of color (300 coins).
Shuffle: rearrange board while preserving a valid move when possible (200 coins).
Color Bomb: destroy a group of selected-color voxels (500 coins).
Every booster has proper icon, description, price, confirmation, actual effect, animation, sound and persistent inventory. Never deduct coins without granting effect; never allow negative balances.
