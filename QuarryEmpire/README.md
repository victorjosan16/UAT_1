# Quarry Empire (Unity 6 LTS, URP, Android portret)

Acest folder conține DOAR codul și structura `Assets/_Game` ale jocului.
Proiectul Unity îl creezi local (Unity Hub → New Project → Universal 3D),
apoi copiezi folderul `Assets/_Game` în folderul `Assets` al proiectului tău.
Unity generează singur fișierele `.meta`.

4 Utilaje · 5 Rafinărie + comenzi · 6 Straturi + generare procedurală ·
7 Muncitori NPC · 8 Salvare, sunete, efecte, meniu · 9 Monetizare + build Play Store
